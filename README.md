# Longform Agent (Dify 版)

> 基于 Dify 平台搭建的长文本生成 Agent，通过多节点工作流实现结构化长文案创作。

[![Dify](https://img.shields.io/badge/Dify-0.8+-blue)](https://dify.ai/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## ✨ 特性

- 📝 **长文本生成**：支持万字级长文案自动创作
- 🔄 **循环扩写**：通过工作流循环节点逐步丰富内容
- ✅ **风格校验**：自动检查文本风格、结构一致性
- 🎯 **多场景适配**：小说、剧本、研究报告、产品文档等
- 🧩 **低代码搭建**：基于 Dify 可视化编排，无需写代码

## 🚀 快速开始

### 导入步骤

1. 登录 [Dify 控制台](https://dify.ai/)
2. 进入「工作室」→「创建应用」→「从 DSL 导入」
3. 选择对应的 `.yml` 文件导入
4. 配置大模型 API Key（支持 OpenAI / 通义 / 豆包等）
5. 发布并测试

### 使用方式

1. 输入写作主题和大纲
2. Agent 自动生成初稿
3. 多轮循环扩写，逐步丰富内容
4. 风格校验通过后输出最终文本
